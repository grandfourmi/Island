Как запустить

1. Запустить IslandApp
2. Ввести параметры
3. Смотреть статистику

Основная логика
- каждый тик совершают действия:
  - Животных 
      - Передвижение, согласно их конфигурационному файлу (КФ), например "6" животное рандомно мб передвинуться 
      0 - 6 клеток.  
      - Едят, согласно этому же КФ будет проверка о возможности питания травой или другими животными в этой клетки,
      с учетом вероятности удачной охоты.
      - Размножение, в случае полных HealsPointe, наличие этого же вида в клетке и если есть возможность добавления
      это вида в клетку оно размножиться.
      - Голод, в конце тика у животного отнимается половина от возможно съеденного за день из HealsPointe.
      если у животного 0 HealsPointe оно умирает.  
   
  - Растения
    - при инициализации программы юзер выбирает количество травы которое добавляется ежедневно

Статистика рассказывает о видах и их количестве выживших на острове, количестве съеденных за тик, и умерших от голода
